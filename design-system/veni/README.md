# Veni design system

Generated and persisted with **UI UX Pro Max** (`--design-system --persist`).

## Usage

1. Read [`MASTER.md`](MASTER.md) for global tokens, components, motion, and checklist.
2. For a specific surface, read [`pages/<page-name>.md`](pages/) if it exists — **page rules override MASTER**.
3. See [`SCOPE.md`](SCOPE.md) for multi-category brand constraints.
