# Private S3 with backend-controlled presigned access

Status: accepted

Product images and payment proofs live in a **private** S3 bucket. Postgres stores object keys and metadata only. The React app never receives AWS secret credentials. Storefront and admin receive time-limited presigned URLs (or upload presigned POST) generated by Django after authorization checks. **CloudFront is not used in Phase 1**; the design keeps bucket/key abstraction so a CDN can be added later without changing domain language.

**Considered options:** Public product bucket (rejected: payment parity and future CDN migration); browser-direct upload with long-lived credentials (rejected).

**Consequences:** Image URLs expire; frontend refreshes URLs as needed. Payment screenshots are readable only by admins via presigned GET after permission check.
