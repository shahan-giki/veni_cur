# Veni frontend

React SPA (Vite + TypeScript). Phase 1: scaffold + design tokens only.

Design rules: [`../design-system/veni/`](../design-system/veni/)

```bash
npm install
npm run dev
npm run build
```

Storefront and `/admin` routes will be added in later phases. API base URL configuration will align with same-origin EC2 deploy (ADR-0006).
